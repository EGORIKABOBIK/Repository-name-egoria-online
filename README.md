# Егория Online V1

Первая интернет-версия мессенджера на Supabase.

## Уже работает

- регистрация по email и паролю;
- уникальный `@username`;
- вход и выход;
- редактирование имени, описания и аватара;
- поиск пользователей;
- создание личной переписки;
- сообщения в реальном времени;
- фото и файлы до 25 МБ;
- реакции ❤️;
- редактирование своих сообщений;
- мягкое удаление своих сообщений;
- поиск по открытой переписке;
- светлая и тёмная тема;
- примерный статус онлайн;
- адаптивный интерфейс и установка на главный экран.

## Перед публикацией

1. Основная схема базы уже должна быть запущена.
2. Запустите `storage_patch.sql` в Supabase SQL Editor.
3. В Supabase откройте Authentication → URL Configuration.
4. После получения адреса Render добавьте его как Site URL и Redirect URL.

## Настройка подключения

При первом открытии сайт попросит:

- Supabase Project URL;
- Supabase publishable key или anon key.

Это публичные клиентские данные. Никогда не используйте `service_role` key.

Можно также заранее вставить публичные значения в `config.js`.

## Развёртывание Render

Это обычный статический сайт. В Render:

- New → Static Site;
- подключить GitHub-репозиторий;
- Branch: `main`;
- Build Command: оставить пустым;
- Publish Directory: `.`;
- нажать Create Static Site.

## Ограничения V1

- пока только личные чаты;
- нет push-уведомлений;
- нет индикатора «печатает»;
- нет групп и каналов;
- доставка зависит от бесплатных лимитов Supabase и Render.
